# Dimpy Birthday Experience ❤️

This is a mobile-first interactive birthday surprise for Dimpy, made from the photos/videos provided by Keshu baby.

## What happens
1. Opening screen
2. Drag the bow/arrow into the heart
3. Pop five balloons
4. Reveal 29 September 2025
5. Browse the photo/video memories
6. Read the birthday letter
7. Blow out three candles
8. Final birthday reveal for 11 September

## Run it
The easiest way is to upload the whole folder to any static web host. It needs no server and no paid service.

For local testing, open `index.html` in a modern browser. Some browsers restrict local video playback; hosting it as a normal website avoids that issue.

The background music is an original tiny Web Audio melody, so there is no copyrighted song file included. If you want a particular song, replace the music section with a song file you own/have permission to use.

## Free hosting
You can upload this folder to GitHub Pages, Netlify, Cloudflare Pages, or another static host. Keep the `assets` folder beside `index.html`.
